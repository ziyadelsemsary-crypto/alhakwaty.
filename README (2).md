# الحكواتي – الموسوعة التاريخية المصرية

موقع ثابت متعدد الملفات، يعمل على GitHub Pages دون خادم خلفي أو قاعدة بيانات مدفوعة.

## التشغيل
- افتح `index.html` للمعاينة الأساسية. بسبب استخدام `fetch` لقراءة JSON قد تمنع بعض المتصفحات تشغيله مباشرة من `file://`.
- للتشغيل المحلي شغّل خادمًا بسيطًا داخل المجلد، مثل: `python -m http.server 8000` ثم افتح `http://localhost:8000`.
- للنشر: ارفع محتويات هذا المجلد إلى مستودع GitHub، ثم فعّل GitHub Pages من Settings → Pages.

## المجلدات
- `articles/`: صفحات المقالات المستقلة.
- `data/`: بيانات المقالات والعصور والشخصيات والأحداث.
- `css/` و`js/`: التصميم والوظائف.
- `sources/`: منهج المصادر وحقوق الصور.
- بقية المجلدات محجوزة للتوسعة المنظمة.

## حدود النسخة الحالية
هذه نسخة تأسيسية فعلية وليست موسوعة مكتملة بالأعداد المستهدفة. تحتوي حاليًا على 3 مقالات، و11 شخصية، و8 أحداث أولية. لم تُضف 200 مقالة أو 1000 صورة؛ لأن نشر محتوى غير محرر أو صور غير متحقق من تراخيصها سيخالف شرط الدقة الذي طلبته. المقالات الحالية تحتاج كذلك إلى إحالات صفحات تفصيلية قبل اعتمادها مرجعًا أكاديميًا نهائيًا.

## التوسعة
أضف كل مقال في `data/site-data.json` ثم أنشئ صفحته في `articles/` بنفس بنية الصفحات الحالية. حافظ على الروابط النسبية كي يعمل الموقع على GitHub Pages.
